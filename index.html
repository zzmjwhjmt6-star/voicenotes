VoiceNotes

ยังเปิดอยู่ใน Safari: กดปุ่ม Share แล้วเลือก Add to Home Screen (เปิด "Open as Web App") จากนั้นเปิดไอคอนบนหน้าโฮม แล้ววาง URL ที่นั่น

ไอคอนบนหน้าโฮมจำ URL แยกจาก Safari จึงต้องวางในไอคอนนั้นอีกครั้ง

ใช้ URL เดียวกับที่วางตอน import Shortcut URL จะถูกเก็บไว้ในเครื่องนี้เท่านั้น ไม่ได้อยู่ในไฟล์บน GitHub
